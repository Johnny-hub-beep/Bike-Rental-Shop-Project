# Bike Rental Shop

A PostgreSQL-backed Bash script for managing a bike rental shop. Built as part of the freeCodeCamp Relational Database Certification.

## Technologies
- Bash
- PostgreSQL

## How to Run
1. Create the database: `psql --username=freecodecamp --dbname=postgres`
2. Make the script executable: `chmod +x bike-shop.sh`
3. Run it: `./bike-shop.sh`

## Features
- View available bikes
- Rent a bike
- Return a bike
- New customers are automatically added to the database
